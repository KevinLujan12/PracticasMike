Cryptographic Authentication & OWASP

Defense-in-Depth Architecture

JWT Token with HMAC-SHA256 Signature Upon successful identification, a structured cryptographic token is synthesized (Header, Payload, and Signature). It is signed using the native browser Web Crypto API via HMAC-SHA256. If any actor attempts to modify credentials or session roles, verification fails instantly and terminates the session.
Anti-Brute Force Mitigation & Timing Attack Defense The engine tracks failed attempts. After 5 erroneous tries, a progressive 30-second lockout is engaged (escalating to 5 minutes after 10 attempts). Every verification incorporates an artificial anti-timing delay to mitigate automated dictionary scanning.
Clickjacking & Inactivity Safeguards The script executes frame-busting (window.top !== window.self) backed by strict headers in vercel.json. If the user remains inactive for 15 minutes, the session is safely revoked.
